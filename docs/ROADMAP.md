# Roadmap

1. **FASE 1 — Arquitectura y motor lógico:** núcleo, modelos, simulación, MVVM base y pruebas. Implementada; su validación automatizada requiere un SDK de .NET instalado.
2. **FASE 2 — Editor gráfico:** componentes visuales, colocación, movimiento, conexiones gráficas WPF, switch/LED, zoom y pan. Implementada; su validación automatizada requiere un SDK de .NET instalado.
3. **FASE 3 — Simulación educativa:** señalización visual, laboratorio libre, guardado/carga JSON, ejemplos y modo Aprender con mini experimentos. Implementada; su validación automatizada requiere un SDK de .NET instalado.
4. **FASE 4 — Juego y gamificación:** desafíos, validación conductual, progreso local, XP, estrellas, rangos, desbloqueos y logros. Implementada; su validación automatizada requiere un SDK de .NET instalado.
5. **FASE 5 — Pulido y entrega:** estilos compartidos, navegación y progreso visibles, feedback de desafíos, revisión estática y documentación final. Implementada; la compilación y pruebas requieren un SDK de .NET instalado.
