# Requisitos

## Alcance actual (Fase 1)

- Tecnología: C#, .NET 10, WPF/XAML y MVVM para la aplicación de presentación.
- Siete compuertas: AND, OR, NOT, NAND, NOR, XOR y XNOR.
- Circuitos combinacionales compuestos por entradas, compuertas, salidas, puertos y conexiones.
- Simulación binaria (`Low = 0`, `High = 1`) y tablas de verdad.
- Validación de conexiones duplicadas, puertos incompatibles, componentes externos, entradas sin conectar y ciclos de realimentación.

## Alcance final

El editor WPF incluye drag & drop y alternativa por clic, cables, zoom/pan, guardado/carga JSON y simulación visual. El modo Aprender, Laboratorio y Desafíos comparte el motor lógico del Core. No se incluyen cuentas, base de datos, servicios online, multijugador ni backend.

## Fase 4

- Desafíos locales validados por comportamiento, progreso, XP, estrellas, rangos, desbloqueos y logros básicos.
- Persistencia de progreso JSON local sin cuentas, servidores ni base de datos.

## Fase 5

- Recursos visuales centralizados, jerarquía de navegación, feedback de acciones principales, accesibilidad mediante ToolTips/contraste y documentación final.
